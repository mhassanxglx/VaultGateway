# VaultGateway

A simple VaultGateway Engine for Load balancing.

VaultGateway is aimed at developers who need a straightforward, dependable solution.

**Highlights**

- A simple VaultGateway Engine for Load balancing

## Key Features

- A simple VaultGateway Engine for Load balancing

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/VaultGateway.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure VaultGateway, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
